# dijkstra — 單源最短路徑

給定一個 `n` 個節點(編號 `0` 到 `n-1`)、`m` 條邊的**無向帶權圖**(邊權重非負),以及一個來源節點 `s`,請計算從 `s` 到每個節點的最短路徑長度(邊權重總和)。若某節點從 `s` 無法到達,輸出 `-1`。

## 輸入
- 第 1 行:兩個整數 `n m`(節點數、邊數)
- 接下來 `m` 行:每行三個整數 `u v w`,代表節點 `u` 與節點 `v` 之間有一條權重為 `w` 的無向邊(`0 <= w`)
- 最後 1 行:一個整數 `s`(來源節點)

## 輸出
- 一行,包含 `n` 個以空白分隔的整數:節點 `0` 到 `n-1` 各自到 `s` 的最短距離;若無法到達則輸出 `-1`。

## 範例
輸入:
```
5 6
0 1 4
0 2 1
2 1 2
1 3 1
2 3 5
3 4 3
0
```
輸出:
```
0 3 1 4 7
```
