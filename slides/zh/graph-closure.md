## 遞移閉包

遞移閉包（Transitive Closure）$R$ 滿足 $R[i][j]=1$，若且唯若從 $i$ 出發存在一條長度至少為 1 的有向路徑到達 $j$。Warshall 演算法以三層迴圈在 $O(V^3)$ 時間內把鄰接矩陣就地擴展成完整的遞移閉包。

---

## 核心概念

$R$ 一開始就是鄰接矩陣本身。演算法逐一把每個頂點 $k$ 當作「允許經過的中繼點」：只要 $i$ 能到 $k$ 且 $k$ 能到 $j$，就把 $R[i][j]$ 補為 1。做完 $k=0,\dots,V-1$ 之後，$R$ 就是完整的遞移閉包。

- 三層迴圈順序固定為 $k,i,j$：$k$ 是最外層，代表逐一「開放」每個中繼點。
- 核心更新規則：`if (R[i][k] && R[k][j]) R[i][j] = 1;`——一旦成立就不會再變回 0。
- 若某頂點 $v$ 位於一個環上，`warshall` 會讓 $R[v][v]$ 變成 1（自己繞一圈可以回到自己）。
- 矩陣就地（in place）更新，不需要額外配置第二份矩陣。

---

## 運作流程

1. 把 $R$ 初始化為鄰接矩陣（有邊 $i\to j$ 就設 $R[i][j]=1$，其餘為 0）。
2. 外層迴圈 $k=0,\dots,V-1$：把 $k$ 當作本輪允許經過的中繼點。
3. 中層迴圈 $i=0,\dots,V-1$、內層迴圈 $j=0,\dots,V-1$：檢查 $R[i][k]$ 與 $R[k][j]$ 是否同時成立。
4. 若兩者皆為 1，代表「$i$ 可到 $k$，$k$ 可到 $j$」，因此設 $R[i][j]=1$。
5. 三層迴圈跑完全部 $k,i,j$ 組合後，$R$ 即為完整的遞移閉包矩陣。

## 逐步範例

輸入：n=4 的有向圖，邊為 0→1、1→2、2→3、3→1（0 是單向入口，1-2-3 構成一個環）。R 初始化為此鄰接矩陣。

1. k=0（以頂點 0 為中介）：檢查所有 i,j 是否 R[i][0] 且 R[0][j]；沒有任何頂點能到達 0（R 的第 0 欄全為 0），故 R 不變。
2. k=1（以頂點 1 為中介）：能到達 1 的有 0 與 3（R[0][1]=R[3][1]=1），而 1 能到達 2（R[1][2]=1）。因此新增 R[0][2]=1 與 R[3][2]=1（經由 1 到 2）。
3. k=2（以頂點 2 為中介）：能到達 2 的有 0、1、3，而 2 能到達 3（R[2][3]=1）。因此新增 R[0][3]=1、R[1][3]=1、R[3][3]=1（經由 2 到 3）。
4. k=3（以頂點 3 為中介）：0、1、2、3 此時都能到達 3，而 3 能到達 1（R[3][1]=1）。因此把「經由 3 到 1」的可及性補上：R[1][1]=1、R[2][1]=1、R[2][2]=1 皆被補為 1——1、2、3 三者從此互相可達。
5. 最終 R：第 0 列為 [0,1,1,1]（0 可達 1、2、3，但無法回到自己）；第 1、2、3 列皆為 [0,1,1,1]（1、2、3 互相可達，但都無法到達 0）。

| R | j=0 | j=1 | j=2 | j=3 |
| --- | --- | --- | --- | --- |
| i=0 | 0 | 1 | 1 | 1 |
| i=1 | 0 | 1 | 1 | 1 |
| i=2 | 0 | 1 | 1 | 1 |
| i=3 | 0 | 1 | 1 | 1 |

## 程式碼

```cpp
#include <iostream>
using namespace std;

const int MAXN = 10;

// Warshall's transitive closure: R[i][j] = 1 iff j is reachable from i via >= 1 edge.
// R is initialized to the adjacency matrix; R[i][i] becomes 1 only if i lies on a cycle.
void warshall(int R[MAXN][MAXN], int n) {
    for (int k = 0; k < n; k++)
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                if (R[i][k] && R[k][j])
                    R[i][j] = 1;
}

int main() {
    int n = 4;                    // SAMPLE: 0->1, 1->2, 2->3, 3->1 (chain + cycle 1-2-3)
    int R[MAXN][MAXN] = {};
    R[0][1] = R[1][2] = R[2][3] = R[3][1] = 1;

    warshall(R, n);

    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++)
            cout << R[i][j] << (j + 1 < n ? " " : "");
        cout << "\n";
    }
    return 0;
}
```
