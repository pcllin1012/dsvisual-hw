## 鄰接多重表

鄰接多重表中,每一條邊只用一個節點(edge-node)表示,同時被兩個端點共享;相較於鄰接串列(每條無向邊要存兩次),空間為 $O(V+E)$。

---

## 核心概念

每個 edge-node 存兩個端點 `v1, v2`,以及兩條「下一條邊」指標 `link1, link2`(分別對應 v1、v2 這一側的鏈);每個頂點有一個 head 指標,起頭串起所有與它相連的 edge-node。

- `nextOf(e, vertex)` 依 vertex 是 e 的 v1 或 v2,回傳對應的 link1 / link2,取得該端點的下一條邊。
- 新增邊時以「插入鏈頭」的方式,把新 edge-node 同時接到兩個端點的鏈上。
- 每條邊只存一個節點,天然適合「每條邊只走訪/標記一次」的演算法(如找橋、Euler 迴路)。
- 空間 $O(V+E)$:V 個 head 指標,加上 E 個 edge-node。

---

## 運作流程

1. 加入邊 $(u, v)$ 時,建立一個新的 edge-node `e(v1=u, v2=v)`。
2. 把 e 接到 u 的鏈頭:先 `setNext(e, u, head[u])`,再讓 `head[u] = e`。
3. 同樣把 e 接到 v 的鏈頭:`setNext(e, v, head[v])`,再讓 `head[v] = e`。
4. 走訪頂點 $i$ 的所有邊時,從 `head[i]` 出發,反覆呼叫 `nextOf(e, i)` 直到 null。

> 每個 edge-node(E0…E5)恰好代表一條邊。頂點 A 的鏈由 head[A] 出發,依插入順序的反序走訪:E5 → E4 → E0,正好是 A 的三條邊 A-C、E-A、A-B。

---

## 逐步範例

輸入:5 個頂點 A–E,無向邊 A-B、B-C、C-D、D-E、E-A、A-C(依此順序呼叫 addEdge)。

1. 依序建立 6 個 edge-node:E0=(A,B)、E1=(B,C)、E2=(C,D)、E3=(D,E)、E4=(E,A)、E5=(A,C)。
2. E0=(A,B) 建立時同時插入 head[A] 與 head[B] 的鏈頭,此刻 head[A] = E0。
3. E4=(E,A) 建立時插入 head[A] 鏈頭,head[A] 變為 E4,且 E4 在 A 這一側的 next 指向先前的 E0。
4. 最後 E5=(A,C) 建立時再插入 head[A] 鏈頭,head[A] 變為 E5,其 next-on-A 指向 E4。
5. 結果:頂點 A 的鏈為 head[A] = E5 → E4 → E0 → null,恰好涵蓋 A 的三條邊 A-C、E-A、A-B。

---

## 複雜度分析

| 項目 | 成本 |
| --- | --- |
| 空間 | $O(V+E)$ |
| 每條邊的儲存次數 | 恰 1 次(鄰接串列需 2 次) |
| 列舉頂點的相鄰邊 | $O(\deg(v))$ |
| 加入一條邊 | $O(1)$ |

## 程式碼

```cpp
#include <iostream>
using namespace std;

// Adjacency multilist: ONE node per undirected edge, shared by both endpoints.
struct ENode {
    int v1, v2;    // the two endpoints of this edge
    ENode *link1;  // next edge incident to v1
    ENode *link2;  // next edge incident to v2
    ENode(int a, int b) : v1(a), v2(b), link1(nullptr), link2(nullptr) {}
};

const int V = 5;
ENode *head[V] = {nullptr};

ENode *nextOf(ENode *e, int vertex) {
    return (e->v1 == vertex) ? e->link1 : e->link2;
}
void setNext(ENode *e, int vertex, ENode *nx) {
    if (e->v1 == vertex) e->link1 = nx; else e->link2 = nx;
}

void addEdge(int u, int v) {
    ENode *e = new ENode(u, v);
    setNext(e, u, head[u]); head[u] = e;   // push onto u's chain
    setNext(e, v, head[v]); head[v] = e;   // same node also pushed onto v's chain
}

void print() {
    for (int i = 0; i < V; i++) {
        cout << "[" << i << "] -> ";
        for (ENode *e = head[i]; e; e = nextOf(e, i))
            cout << "(" << e->v1 << "," << e->v2 << ") -> ";
        cout << "null\n";
    }
}

int main() {
    addEdge(0, 1); addEdge(1, 2); addEdge(2, 3);
    addEdge(3, 4); addEdge(4, 0); addEdge(0, 2);
    print();
    return 0;
}
```
