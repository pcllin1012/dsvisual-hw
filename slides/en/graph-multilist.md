## Adjacency Multilist

In an adjacency multilist, each edge is represented by a single edge-node shared by both of its endpoints — unlike an adjacency list, which stores every undirected edge twice. Space is $O(V+E)$.

---

## Core Concept

Each edge-node stores its two endpoints `v1, v2` plus two "next edge" pointers `link1, link2` (one per endpoint’s chain); every vertex has a head pointer that threads together all edge-nodes incident to it.

- `nextOf(e, vertex)` returns link1 or link2 depending on whether vertex is e's v1 or v2 — the next edge on that endpoint's chain.
- Adding an edge prepends the new edge-node onto both endpoints' chains (pushes it to the head).
- Because each edge is a single node, algorithms that must visit or mark each edge exactly once (bridges, Euler tours) fall out naturally.
- Space $O(V+E)$: V head pointers plus E edge-nodes.

---

## Operation Flow

1. To add edge $(u, v)$, create a new edge-node `e(v1=u, v2=v)`.
2. Splice e onto u's chain head: `setNext(e, u, head[u])`, then `head[u] = e`.
3. Do the same on v's side: `setNext(e, v, head[v])`, then `head[v] = e`.
4. To walk all edges at vertex $i$, start at `head[i]` and repeatedly call `nextOf(e, i)` until null.

> Each edge-node (E0…E5) represents exactly one edge. Vertex A’s chain starts at head[A] and visits edges in reverse insertion order: E5 → E4 → E0 — precisely A’s three incident edges A-C, E-A, A-B.

---

## Worked Example

Input: 5 vertices A–E, undirected edges A-B, B-C, C-D, D-E, E-A, A-C (added via addEdge in this order).

1. Six edge-nodes are created in order: E0=(A,B), E1=(B,C), E2=(C,D), E3=(D,E), E4=(E,A), E5=(A,C).
2. When E0=(A,B) is created, it is pushed onto both head[A] and head[B]; at this point head[A] = E0.
3. When E4=(E,A) is created, it is pushed onto head[A]; head[A] becomes E4, whose next-on-A pointer chains back to the earlier E0.
4. Finally E5=(A,C) is created and pushed onto head[A]; head[A] becomes E5, whose next-on-A pointer points to E4.
5. Result: vertex A's chain is head[A] = E5 → E4 → E0 → null, covering exactly A's three incident edges A-C, E-A, A-B.

---

## Complexity Analysis

| Aspect | Cost |
| --- | --- |
| Space | $O(V+E)$ |
| Storage per edge | exactly once (an adjacency list needs twice) |
| Enumerate a vertex's incident edges | $O(\deg(v))$ |
| Add edge | $O(1)$ |

## Source Code

```cpp
#include <iostream>
using namespace std;

// Adjacency multilist: ONE node per undirected edge, shared by both endpoints.
struct ENode {
    int v1, v2;    // the two endpoints of this edge
    ENode *link1;  // next edge incident to v1
    ENode *link2;  // next edge incident to v2
    ENode(int a, int b) : v1(a), v2(b), link1(nullptr), link2(nullptr) {}
};

const int V = 5;
ENode *head[V] = {nullptr};

ENode *nextOf(ENode *e, int vertex) {
    return (e->v1 == vertex) ? e->link1 : e->link2;
}
void setNext(ENode *e, int vertex, ENode *nx) {
    if (e->v1 == vertex) e->link1 = nx; else e->link2 = nx;
}

void addEdge(int u, int v) {
    ENode *e = new ENode(u, v);
    setNext(e, u, head[u]); head[u] = e;   // push onto u's chain
    setNext(e, v, head[v]); head[v] = e;   // same node also pushed onto v's chain
}

void print() {
    for (int i = 0; i < V; i++) {
        cout << "[" << i << "] -> ";
        for (ENode *e = head[i]; e; e = nextOf(e, i))
            cout << "(" << e->v1 << "," << e->v2 << ") -> ";
        cout << "null\n";
    }
}

int main() {
    addEdge(0, 1); addEdge(1, 2); addEdge(2, 3);
    addEdge(3, 4); addEdge(4, 0); addEdge(0, 2);
    print();
    return 0;
}
```
